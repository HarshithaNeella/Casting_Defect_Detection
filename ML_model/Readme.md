# Machine Learning Model (HOG + SVM)

## 📌 Overview
This module implements casting defect detection using traditional Machine Learning techniques.

---

## ⚙️ Approach
- Feature Extraction: Histogram of Oriented Gradients (HOG)
- Model: Support Vector Machine (SVM)
- Input: Grayscale images
- Output: Binary classification (Defective / OK)

---

## 🔍 Workflow
1. Image preprocessing (grayscale, resizing)
2. Feature extraction using HOG
3. Model training using SVM
4. Prediction on test images

---

## ▶️ Run
python ml_app.py


---

## ⚠️ Limitation
- Requires manual feature engineering
- Limited ability to capture complex patterns compared to CNN
